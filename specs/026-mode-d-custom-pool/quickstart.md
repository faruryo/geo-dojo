# Quickstart & Validation Guide: Mode D 市区町村出題選択・絞り込み

## Prerequisites

- ローカル開発サーバー起動: `pnpm dev`
- テスト実行: `pnpm test`
- 型チェック: `pnpm type-check`

---

## 1. ユニットテストでの検証シナリオ

```bash
# スコープフィルタおよび出題生成テストの実行
pnpm vitest run __tests__/lib/quiz/municipality-scope.test.ts
pnpm vitest run __tests__/lib/quiz/municipality-questions.test.ts
```

### 期待されるテストケース
1. `filterByScope`:
   - 地方指定（`type: 'region'`, `regions: ['近畿']`）で近畿地方の自治体のみが返ること。
   - 都道府県指定（`type: 'prefecture'`, `prefecture: '長野県'`）で長野県の全自治体が返ること。
   - 個別コード指定（`type: 'prefecture'`, `prefecture: '長野県'`, `selectedCodes: ['20201', '20202']`）で指定2件のみが返ること。
2. `buildMunicipalityQuestions`:
   - Mode D で特定都道府県またはカスタムコードを指定した際、指定自治体のみから問題が生成されること。
   - 問題数（10問）より少ない自治体数（3件）が指定された場合でもエラーにならず、重複なしの3問で構成され完了できること。

## 2. ブラウザ UI でのエンドツーエンド検証

1. ブラウザで `http://127.0.0.1:3000/quiz/municipality/d` にアクセス。
2. 出題範囲で「都道府県で選ぶ」を選択。
3. 都道府県ピッカーから「長野県」を選択。
   - 画面の制覇進捗バーが長野県の母数（77件）とクリア数に更新されることを確認。
4. 「市区町村を選択 (77/77件)」ボタンをタップして選択モーダル/ドロワーを開く。
5. 「全解除」をタップ後、検索ボックスに「松本」と入力し、「松本市」のみにチェックを入れる。
6. 「決定 (1件選択)」をタップして設定画面に戻る。
   - スタートボタン下に「該当 1 件のみ — 全 1 問で出題されます」が表示されることを確認。
7. 「スタート」をタップしてクイズ開始。
   - 出題が「松本市」となり、長野県の地図上にポリゴンが表示され、タップして回答・正誤判定できることを確認。
8. クイズ終了後（全1問）、結果画面で「もう一度」をタップ。
   - 再び同じカスタムプールでクイズが開始されることを確認。
