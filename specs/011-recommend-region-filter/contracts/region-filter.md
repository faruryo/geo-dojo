# 契約定義書 (Contracts): 地域絞り込み機能のコンポーネント・URL契約

## 1. URL クエリパラメータ契約

今日のおすすめクイズ（`RecommendContent`）からクイズページ（`/quiz/municipality/[mode]`）へ遷移する際、以下のクエリパラメータを引き渡します。

| パラメータ | 役割 | 形式 | 例 |
|---|---|---|---|
| `region` | 選択された地方のフィルタ | カンマ区切りの文字列 | `region=東北,関東` |

### 整合性ルール
- クイズ開始時のパースロジックは、無効な地方名（`REGIONS` に含まれない値）を無視しなければなりません。
- 「全国」がクエリパラメータに含まれている場合、または指定がない場合は全地方を出題対象とします。

---

## 2. UI 状態連携契約（シート内オーバーライド）

調整ダイアログの開始パラメータは、未操作時は推薦エンジンの選定を使い、ユーザーが「内容を変える」で明示操作したときだけ差し替える。

### ライフサイクル仕様
- **マウント時**:
  - 推薦エンジンの `mode` / `count` / `regions` / `difficulties` を初期値とする。
  - LocalStorage（旧キー `geodojo-recommend-region-filters`）は読み書きしない。過去の保存値で初期表示や開始パラメータを上書きしてはならない。
- **明示操作時**:
  - ユーザーがモード・問題数・難易度・地方をトグルした内容だけを、そのシート表示中の `overrides` として親へ伝える。
  - 推薦データ（セッションキー）が変わったら `overrides` は破棄し、新しい推薦に追従する。
