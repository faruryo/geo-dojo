# Feature Specification: 逆引き制覇の非対称クレジット

**Feature Branch**: `023-reverse-coverage-credit`

**Created**: 2026-08-30

**Status**: Draft

**Input**: User description: "モードA/Bは実質同じ（市区町村名→都道府県）なのに制覇が別枠で、両方やらないと全国制覇が増えない。Aの方が明らかに難しい。A正解をB制覇にも効かせたいが、A1問で全体ゲージが2倍に増えるのは避ける。説明を書いておく。おすすめの出し方も揃える。復習キューは統合しない。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 全国制覇は逆引きを1枠として進む (Priority: P1)

学習者はダッシュボードの全国制覇（全体）を見る。逆引き地図（A）か逆引き4択（B）のどちらかで正解した市区町村（名前と都道府県の組）は、逆引きとして1回だけクリアと数えられる。順引き4択（C）と地図タップ（D）はこれまでどおり別枠である。Aだけ攻略しても、同じ組についてBをやり直さなくても全体ゲージは進む。Aの1回の正解で、全体の分子が逆引きとBの2枠ぶん一気に増えることはない。

**Why this priority**: 「両方やらないと増えない」と「Aが得しすぎる」の両方をここで解消する。これが本機能の本体である。

**Independent Test**: Aのみで正解した組と、Bのみで正解した組と、未正解の組を用意し、全体のクリア数・総数が「逆引き1枠＋C＋D」になっていること、A正解が分子を2枠分動かしていないことを確認する。

**Acceptance Scenarios**:

1. **Given** ある市区町村（名前と都道府県の組）をモードAで正解し、B/C/Dでは未正解であるとき, **When** 全国制覇（全体）を見る, **Then** その組は逆引きクリアとして1枠だけ数えられ、B用の第2枠としては数えられない。
2. **Given** 同じ組をモードBでのみ正解しているとき, **When** 全国制覇（全体）を見る, **Then** 逆引きはクリアとして1枠数えられ、モードA単体のゲージは増えない。
3. **Given** モードCまたはDだけで正解しているとき, **When** 全国制覇（全体）を見る, **Then** 当該モードの枠だけが増え、逆引き枠は埋まらない。

---

### User Story 2 - モードBの制覇進捗はA正解でも埋まる (Priority: P1)

学習者がモードBの設定画面や、ダッシュボードでモードBに絞った制覇を見るとき、同じ名前と都道府県の組をAで正解していればBでもクリアと表示される。Bだけ周回しなくてもBのバーは100%になり得る。モードAに絞ったゲージは、Bの正解では埋まらない。

**Why this priority**: Bを練習用の入口として残しつつ、制覇のためにBを義務にしない。

**Independent Test**: A正解のみの学習者でBフィルタのクリア数が分母まで届くこと、B正解のみではAフィルタのクリア数が増えないことを確認する。

**Acceptance Scenarios**:

1. **Given** 対象プールの全市区町村組をAで正解しBでは一度も解いていないとき, **When** モードBの制覇進捗を見る, **Then** クリア数が総数と一致し、制覇済みと分かる。
2. **Given** 同じ組をBでのみ正解しているとき, **When** モードAの制覇進捗を見る, **Then** その組は未クリアのままである。
3. **Given** 難易度別の制覇や、おすすめの「今の難易度を十分制覇してから次へ」判定を見るとき, **When** モードB側の制覇率を計算する, **Then** A正解がBクリアに含まれる（全体・B設定画面と同じ定義）。

---

### User Story 3 - 制覇の数え方が画面上で分かる (Priority: P1)

学習者は、全体の全国制覇と、モードBの制覇進捗の近くで、A正解がB（および全体の逆引き）に効くことを1行で読める。長く説明しない。見えないとバグに見える動きを、その場で回収する。

**Why this priority**: 非対称クレジットは黙っていると不信になる。

**Independent Test**: 該当2箇所に説明があり、モードAのみ・Cのみ・Dのみの画面では必須としない（A単体はクレジット先ではない）。

**Acceptance Scenarios**:

1. **Given** ダッシュボードの全国制覇が全体表示であるとき, **When** ゲージ付近を見る, **Then** 「逆引き地図（A）で正解した市区町村は、4択（B）でも制覇済みになります。」と同等の1行がある。
2. **Given** 市区町村クイズの設定がモードBであるとき, **When** 制覇進捗を見る, **Then** 同じ趣旨の1行がある。

---

### User Story 4 - おすすめは制覇の定義に合わせて逆引きを出す (Priority: P2)

学習者が「今日のおすすめ」を見る。回答が少ないうちは今どおり逆引き4択（B）から入る。地図（A）が安定して得意ゾーンに入ったあとは、Bを「まだやっていない形式」として押し付けない。BだけやってA未挑戦なら、ときどきAを出してよい（易しい方から難しい方へ）。逆引きの穴埋めは、AでもBでもまだ正解していない組を優先する。復習（間隔反復）のキューはAとBで別のままである。

**Why this priority**: ゲージだけ直しておすすめがB周回を勧めると、また「両方やれ」になる。

**Independent Test**: Aが得意ゾーンに入った学習者におすすめがBを未挑戦として出さないこと、Aで埋まった組をBの穴埋めとして出さないこと、コールドスタートはBであること。

**Acceptance Scenarios**:

1. **Given** 学習開始直後（回答が少ない）とき, **When** おすすめを出す, **Then** モードはBである。
2. **Given** モードAが得意ゾーンに入っているとき, **When** おすすめの形式を決める, **Then** Bを未挑戦モードとして選ばない。
3. **Given** Bはプレイ済みだがAは未挑戦のとき, **When** 新しい形式を混ぜる, **Then** Aを候補にしてよい。
4. **Given** ある組をAで既に正解しているとき, **When** 逆引きの未制覇を埋めるおすすめを組む, **Then** その組をB用の未プレイとして出さない。
5. **Given** おすすめが「モードBは未挑戦」と案内する条件, **When** A安定後にB注入を止めたあと, **Then** その案内は出ない。

---

### Edge Cases

- 伊達市のように同名で複数県がある場合、Aは1問にまとまるが保存は県ごとである。全体・Bのクリアは、正解として残った県の組にだけ効く。不正解の県にはクレジットしない。
- 県名と市区町村名が一致するもの（青森市など）は、現行どおりA/B/Cの制覇母数から除外する。
- 既存のA正解は、機能公開後に再プレイしなくてもBおよび全体の逆引きクリアに含める。
- モードC・Dの制覇定義は変えない。
- 復習対象の出し入れは、A正解があってもBの復習カードを消さない。
- 全体フィルタ以外（Aのみ表示）では、説明1行は必須ではない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 全国制覇（全体）の総数は、逆引き（名前と都道府県の組）＋順引き4択（同じ組単位）＋地図タップ（市区町村一件ずつ）でなければならず、逆引き地図用の「名前だけの別枠」を足してはならない。
- **FR-002**: 全国制覇（全体）の逆引きクリアは、その組をモードAまたはモードBで1回以上正解していれば1枠とし、AとBの両方で正解しても2枠にしてはならない。
- **FR-003**: モードBの制覇（設定画面・ダッシュボードのBフィルタ・難易度別のB・おすすめの制覇率ゲート）は、同じ組のモードA正解をクリアとして数えなければならない。
- **FR-004**: モードAの制覇はモードAの正解のみとし、モードBの正解で埋めてはならない。
- **FR-005**: モードCおよびモードDの制覇の数え方を、本機能のために変えてはならない。
- **FR-006**: 制覇の定義は、全国制覇・難易度別・設定画面の進捗・おすすめの制覇率による難易度進行判定で一致しなければならない。
- **FR-007**: ダッシュボードの全国制覇が全体のとき、およびモードBの設定画面の制覇進捗のとき、A正解がB制覇に効く旨を1行で表示しなければならない。文言は「逆引き地図（A）で正解した市区町村は、4択（B）でも制覇済みになります。」と同等とする。
- **FR-008**: おすすめは、回答が少ない学習者にはモードBを出さなければならない。
- **FR-009**: おすすめは、モードAが得意ゾーンに入っている学習者に、モードBを未挑戦形式として選んではならない。
- **FR-010**: おすすめは、モードB経験がありモードA未挑戦のとき、モードAを新しい形式の候補にしてよい。
- **FR-011**: おすすめの逆引き穴埋めは、モードAでもBでも未正解の組を未制覇とし、A正解済みの組をBの未プレイとして出してはならない。
- **FR-012**: 間隔反復の復習キューはモード別に維持し、A正解を理由にBの復習を完了扱いにしてはならない。
- **FR-013**: 過去の正解履歴を消し直したり、学習者に再回答を求めたりせず、公開後の集計に既存A正解を含めなければならない。

### Key Entities

- **逆引き枠**: 市区町村の名前と都道府県の組。全国制覇（全体）ではAとBで共有する1枠。
- **モード別制覇**: 画面フィルタA/B/C/Dごとのクリア。BだけAからのクレジットを受ける。
- **正解履歴**: 学習者がいつどのモードでその市区町村に正解したか。クレジットは正解がある組にだけ効く。
- **おすすめ**: 次に勧めるモード・地域・難易度と出題の穴埋め。制覇定義と矛盾しないこと。
- **復習カード**: モードごとの間隔反復。本機能では結合しない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Aのみで全市区町村組を正解した学習者の全国制覇（全体）は、Bを一度も解いていなくても逆引き分が100%になり、分子が「逆引き＋C＋D」の総数を超えない。
- **SC-002**: 同じ学習者のモードB制覇進捗は100%になり、モードA制覇はB未プレイのままでもA側の正解だけで埋まる（B側プレイは不要）。Bのみ正解の学習者ではモードA制覇は0のままである。
- **SC-003**: 全体ゲージで、Aの1組正解によるクリア増加は1枠であり、2枠ではない（C/D未プレイのとき逆引きだけが増える）。
- **SC-004**: 該当2箇所（全体の全国制覇、モードB設定の進捗）で、クレジットの1行説明が初見で読める。
- **SC-005**: Aが得意ゾーンの学習者に対し、おすすめがBを未挑戦として出さず、A正解済み組をB穴埋めにも出さない。
- **SC-006**: 復習一覧で、Aだけ正解した組のBカードが、クレジットを理由に消えない。

## Assumptions

- 対象はログイン済みの市区町村クイズ学習者。都道府県クイズは対象外。
- モードA/B/C/Dの出題UI自体は残す。逆引きを1つの選択カードに統合したり、Bを廃止したりしない。
- 同一名除外など、既存の出題・制覇から外す市区町村の扱いは変えない。
- 「得意ゾーン」は現行のおすすめが使う安定正答の帯を指す。新しい正答率の閾値は導入しない。
- スキーマ追加や履歴の一括書き換えは不要。数え方の変更だけで足りる。
- モバイル幅375px・ダークモードの既存見た目に、説明1行を足す程度の変更に収める。

## Out of Scope

- モード選択画面でAとBを1モードに統合すること
- モードBの廃止
- 復習（間隔反復）レコードの統合・移行
- モードCとモードDを同様に1枠へまとめること
