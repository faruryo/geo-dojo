# Data Model: 024-conquest-mode-a

新テーブルは追加しない。既存 `municipality_quiz_results` / `municipality_master` / `srs_records` の DDL は必須変更しない。

## 県当て制覇（A）

| 項目 | 定義 |
|------|------|
| 単位 | 市区町村 `name`（現行 Mode A。同一名除外あり） |
| クリア | その name について mode=A かつ `is_correct=true` が1件以上 |
| トップ分母 | 全国（北海道を含む）の現行 A 母数 |
| おすすめ90% | 地方×難易度マス。抽選対象地方から北海道を除く。除いた地方は「全市」に入れない |

## 場所当て制覇（D）

| 項目 | 定義 |
|------|------|
| 単位 | `municipality_code` |
| クリア | そのコードについて mode=D かつ `is_correct=true` が1件以上 |
| 政令市 | 区コードは別マス。一区の正解で同市他区をクリアにしない |
| トップ分母 | マスタ全コード（北海道を含む） |

B/C の正解はどちらの全国制覇にも入れない。SRS 復習はモード別のまま（A 正解で他モードの due を消さない）。

## 地方×難易度マス

- 地方: 現行 `REGION_VALUES`（北海道〜九州）
- 難易度: 入門 / 中級 / 上級 / 達人（現行 `DIFFICULTY_ORDER`）
- 制覇率: そのマスの出題単位のうちクリア数 / 総数
- 開始不能: モード A かつ地方=北海道。おすすめ候補から除外
- D および C は北海道可。B はおすすめ差し替え先になり得るが、A 抽選が北海道を含まないため差し替え後の B は開始不能にならない

## おすすめ

入力:

- マスタ（code, name, prefecture, region, difficulty）
- モード別クリア済みコード
- RNG
- クライアントの苦戦メタ（下記）
- 任意の地域オーバーライド（011 の既存フィルタ。抽選後のプールに掛ける場合は現行どおり）

出力（既存 `Recommendation` を維持し、意味だけ変える）:

- `mode`: A/D、または差し替え後の B/C
- `regions`: 原則1地方
- `difficulties`: 原則1難易度
- `count`: 現行どおり直近問数の最頻（10/20/30）
- `codes`: 重複回避用履歴。出題サンプリングの上書きには使わない（022）
- rationale: 抽選結果に合う文言

## A セッション（苦戦）

クライアント記憶。永続は localStorage（recommendation history 拡張）。

| フィールド | 意味 | 検証 |
|------------|------|------|
| `quizSessionId` | クイズ開始で発行。退出まで不変 | 連続開始は別 ID |
| `mode` | そのランのモード | |
| `questionResults` | 保存した表示1問の正誤 | Mode A は県別行を1問に正規化 |
| `accuracy` | 正答数 / 答えた問数 | 未回答除外。0問ならレコード自体なし |
| `swapConsumedForASessionId` | この A sessionId で B/C 差し替え済みならその ID | 次の A 引きは差し替えない |

直近 B/C: `mode × region × difficulty` キーで last session を持つ。モードあたり1件だと後続プレイや全国セッションが別マスを潰す。複数マスにまたがる1回は、答えた問があるマスだけをその問の正答率で更新する。セッション切り出しをサーバーの 30 分窓にしない。

中断・popstate: `onAbort` が結果を渡さない現状では lastA が欠ける。保存成功のたびに正規化1問をセッションバッファへ載せ、退出時はバッファ＋未反映の保留保存を突き合わせて書く。

## モード D 出題

| フィールド | 意味 |
|------------|------|
| `municipality.code` | 正答コード。タップ比較の唯一のキー |
| `name`（マスタ） | A/B/C 用。政令市は市名のまま |
| `locationLabel` | D 回答前・フィードバック。コードに対する区付き名。無いコードは `name` |

## 状態遷移（おすすめ）

```text
抽選対象のそのモードに 90%未満マスがある:
  [A/D コイン]
      → 地方抽選（90%済み地方は引き直し）
      → 難易度 = その地方×モードで 90%未満の最易
      → 苦戦差し替え（下記）

全市が 90%以上（最小マス規則 FR-010）:
  コインと「最易難易度」は使わない
      → 開始できる A/D の地方×難易度マスから制覇率最小（同率は均等）
      → 選んだマスの mode / region / difficulty をそのまま使う
      → 苦戦差し替え（下記）

苦戦差し替え:
  mode==A かつ 直近Aあり かつ accuracy<0.3 かつ そのAへ未差し替え
       かつ 同マスの直近B/Cが「低くない」で揃っていない
       → B/C 候補から均等（低い or セッションなし）。地方・難易度は維持
  mode==D → モード固定
```
