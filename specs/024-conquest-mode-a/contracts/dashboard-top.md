# Contract: ダッシュボード・トップとモード選択

## トップに出すもの

- 今日のおすすめ（既存ヒーロー）
- 県当て制覇バー（mode A 固定。北海道を分母に含む）
- 場所当て制覇バー（mode D 固定。コード単位）
- 復習カード（モード別 SRS。クロスモードで消さない）

## トップに出してはならないもの

- 合算の全体制覇率（SummaryCards「全国制覇」、`mode=all` の CompletionProgress、合算 MilestoneBanner）
- B/C のクリア数・練習消化
- 正答率推移チャート
- 苦手ランキング
- 制覇率推移チャート（詳細分析へ移す前提。本仕様ではページを作らない）

A のみ全市正解 → A バー 100%、D 未プレイなら D バー 0%。B/C のみでは両バー不変。

既存 `getCompletionByMode({ mode: 'A' | 'D' })` を2本表示に使う。合算クエリはトップから呼ばない（関数削除は必須としない）。

## モード選択 UI

パス `/quiz/municipality`。URL セグメントは `A` `B` `C` `D` のまま。

表示（同等で可）:

| 記号 | ラベル |
|------|--------|
| A | 県当て（地図） |
| B | 県当て（4択）・練習と分かること |
| C | 市当て（4択）・練習と分かること |
| D | 場所当て（地図） |
