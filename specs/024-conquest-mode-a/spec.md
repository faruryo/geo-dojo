# Feature Specification: 制覇は県当て地図と場所当て地図、おすすめはA/D抽選

**Feature Branch**: `024-conquest-mode-a`

**Created**: 2026-08-30

**Status**: Draft

**Supersedes**: `023-reverse-coverage-credit`（A/Bを1枠にまとめる方針。未実装のまま本仕様で置き換える）

**Input**: User description: "全国制覇をモード横断で足すとB/Cまで必須になり、Aと実質同じ知識を二周する。Aを県当ての本番、B/Cを練習、Dを場所当てとして別ゲージにする。おすすめはAかDを半々。苦戦（直近Aの正答率）のときだけBCD。トップはおすすめとA/D制覇だけ。詳細分析は次仕様。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 全国制覇は県当てと場所当てを別々に見る (Priority: P1)

学習者はダッシュボードのトップで、県当て地図（A）の制覇と場所当て地図（D）の制覇を別バーで見る。合算の「全体○%」は出ない。B/Cの練習クリアはトップに出ない。AのクリアはAバーだけ、DのクリアはDバーだけを進める。

**Why this priority**: 足し算の分母が「同じ知識の二周」と「探せば当たるD」を混ぜるのが、これまでの不満の本体だから。

**Independent Test**: Aだけ正解した学習者でAバーだけが増えDは動かないこと。Dだけ正解で逆であること。B/Cだけの正解ではどちらの全国制覇バーも増えないこと。合算%が無いこと。

**Acceptance Scenarios**:

1. **Given** ある市区町村をモードAでのみ正解しているとき, **When** トップの制覇を見る, **Then** Aバーだけが増え、Dバーと合算%は増えない（合算は表示されない）。
2. **Given** 同じ市区町村をモードDでのみ正解しているとき, **When** トップの制覇を見る, **Then** Dバーだけが増える。
3. **Given** モードBまたはCでのみ正解しているとき, **When** トップの制覇を見る, **Then** AバーもDバーも増えない。
4. **Given** ダッシュボードのトップを開いたとき, **When** 画面を見る, **Then** おすすめとA制覇とD制覇があり、B/Cのクリア数や合算全国制覇は無い。
5. **Given** 政令市の一区だけをモードDで正解しているとき, **When** D制覇と未クリア優先を見る, **Then** 同市の他区は未クリアのままである。
6. **Given** 政令市のある区がDの出題であるとき, **When** 同市の別区の地図をタップする, **Then** その問いは不正解であり、出題コードはクリアにならない。
7. **Given** 政令市の区がモードDの出題であるとき, **When** 回答前の問題文を見る, **Then** 区が分かり、市名だけでは区別できない。

### User Story 2 - モードの呼び方が役割と一致する (Priority: P1)

学習者はモード選択で、記号A/B/C/Dに日本語が添えてあるのを見る。Aは県当て（地図）、Bは県当て（4択）の練習、Cは市当て（4択）の練習、Dは場所当て（地図）と分かる。

**Why this priority**: 記号だけだと本番と練習が区別できない。

**Independent Test**: モード選択画面で4つとも短い日本語があり、BとCに練習であることが分かること。

**Acceptance Scenarios**:

1. **Given** 市区町村クイズのモード選択を開いたとき, **When** 各カードを見る, **Then** A「県当て（地図）」、B「県当て（4択）」練習、C「市当て（4択）」練習、D「場所当て（地図）」と同等の表示がある。

### User Story 3 - おすすめはAかDを半々し、その地方の未制覇難易度を出す (Priority: P1)

学習者が「今日のおすすめ」を見る。まずAかDを50%で選ぶ。選んだモードについて、そのモードでクイズが成立する地方から均等ランダムに選ぶ（Aは都道府県が1つだけの地方を除く）。その地方で全難易度が制覇90%以上なら地方を引き直す。残った地方×モードで、制覇90%未満のうち一番易しい難易度を使う。出題は未クリア優先。全市地方がそのモードで90%以上なら、AとDのうち開始できるマスから制覇率が最小の地方×難易度を選ぶ（同率は均等ランダム）。Aを引いたときだけ、直近Aセッションの正答率が低ければB/C/Dに逃げる（D50%・B25%・C25%）。逃げるときは地方と難易度はAで決めたものを維持する。同じ直近Aセッションに対する差し替えは1回までとし、次のA抽選はAのまま出す。Dを引いたときは正答率でモードを変えない。

**Why this priority**: 能力が未知なら簡単すぎる入口にしない。制覇の穴は選んだモードの地方×難易度で埋める。Aの地図で苦戦しているときだけ4択と場所当て練習に落とす。

**Independent Test**: 苦戦前・最小マス規則前なら多数回のおすすめでAとDがおよそ半々であること。Aのおすすめで北海道だけが地方になることがないこと。ある地方の入門が90%・中級が50%なら中級が選ばれること。90%済み地方は引き直されること。A引いて低正答率ならBCDの比率になること。D引きではBCDに落ちないこと。回答後におすすめが古いまま残らないこと。

**Acceptance Scenarios**:

1. **Given** 苦戦しておらず、選んだモードがまだ全市90%未満の学習者, **When** おすすめのモードを多数回決める, **Then** AとDがおよそ半数ずつになる。
2. **Given** モードA・関東の入門が90%・中級が50%のとき, **When** Aかつ関東が選ばれたおすすめを出す, **Then** 難易度は中級で、未クリア優先である。
3. **Given** ある地方のそのモードが全難易度90%以上のとき, **When** 地方を抽選する, **Then** その地方は捨てて引き直す。
4. **Given** 抽選対象の全市地方がそのモードで90%以上のとき, **When** おすすめを出す, **Then** AとDのうち開始できる地方×難易度マスから制覇率が最小のものを選び、同率なら均等に選ぶ。
5. **Given** おすすめがAを引き、直近Aセッションの正答率が低く、そのセッションに対する差し替えがまだ無いとき, **When** 形式を決める, **Then** Dが約50%、Bが約25%、Cが約25%で、地方と難易度はA抽選の結果のままである。
6. **Given** おすすめがDを引いたとき, **When** 直近Aの正答率が低い, **Then** モードはDのままである。
7. **Given** おすすめを見たあとにクイズを完了し、結果からおすすめへ戻るとき, **When** 推薦を見る, **Then** 回答前のキャッシュのまま残らない。
8. **Given** おすすめがAを引いたとき, **When** 地方を決める, **Then** 北海道だけを対象にしたAにはならない。
9. **Given** 直近のAセッションに同名・複数県の1問が含まれるとき, **When** 苦戦判定する, **Then** 表示1問1件でセッションサイズと正答率を見る。
10. **Given** 直近Aが低正答で、おすすめがすでに1回BCDへ差し替え済みのとき, **When** 次にAを引く, **Then** モードはAのままである。

### User Story 4 - トップから外した数字は詳細分析で見る前提にする (Priority: P2)

学習者はトップで次にやる内容とA/D制覇だけを見る。正答率推移、苦手ランキング、B/Cの練習消化などはトップに無い。これらは詳細分析ページで見る。そのページ自体はこの仕様では作らない。

**Why this priority**: トップを「次にやる／A／D」に薄くするため。移し先を書かないとデータが消えたように見える。

**Independent Test**: トップに推移グラフやB/Cクリアが無いこと。仕様に詳細分析への移行が書いてあること。

**Acceptance Scenarios**:

1. **Given** トップを開いたとき, **When** スクロールする, **Then** 正答率推移・苦手ランキング・B/C練習クリアは無い。
2. **Given** 詳細分析ページがまだ無いとき, **When** 本機能を出す, **Then** トップから外した項目は詳細分析へ移すことが仕様上の前提であり、ページ実装は後続仕様である。

---

### Edge Cases

- 伊達市など同名複数県は、モードAでは名前集約の1問・保存は県ごと。A制覇の単位は現行Aと同じ（同一名除外あり）。
- モードDの制覇・未クリア優先・おすすめ90%は市区町村コード単位とする。政令市の区は別マスであり、一区の正解で同名市の他区をクリア済みにしてはならない（022のB/C集約はDには適用しない）。
- モードDの正誤はタップした市区町村コードで判定する。表示名が同じ兄弟区をタップしても、出題コードの正解にしてはならない。フィードバックも兄弟コードへ正解を付けてはならない。
- モードDの回答前表示は、出題コードを他コードと区別できなければならない。政令市の区は区が分かる名前（または同等の識別）を出す。
- 苦戦差し替えは、同じ直近Aセッションに対しておすすめのA抽選を1回までとする。次のA抽選は差し替えずAを出す。手動でAを完了しても直近セッションは更新される。
- 直近Aセッションの正答率は、保存行数ではなく表示1問につき1件に正規化してから現行の苦手判定に渡す。同名・複数県の1問で行が増えても、出題数10/20/30のセッションとして扱えなければならない。
- 全市地方が90%未満のマスを持つあいだは、90%済み地方だけ引き直す。AとDの全市が90%以上になったら最小制覇マス規則に切り替える。
- 引き直しで残る地方が0なら（そのモードの全市90%以上）、最小制覇マス規則を使う。
- 最小マスの制覇がすべて100%なら、そのなかから均等ランダムで通常出題する。
- 直近Aセッションが無いコールドスタートは苦戦とみなさず、A/D半々から入る。
- 「正答率が低い」は現行おすすめの直近セッション正答率の苦手判定を流用する（新しい閾値は作らない）。
- 復習カードはモード別に残す。A正解でB/C/Dの復習は消さない。
- 「数え方とおすすめとトップの構成を変える」に加え、モードDの正誤をコード単位に揃える（現行の同一表示名判定は本仕様で置き換える）。
- 県当て（A）と県当て4択（B）は、都道府県が1つだけの地方では成立しない。おすすめのA地方抽選から北海道を除く。Dと市当て4択（C）は北海道を含めてよい。トップのAバー分母は現行どおり北海道を含む。学習者がモード選択で他地方と組み合わせればAの北海道は解ける。
- 最小制覇マス規則でも、開始できないマス（AまたはBかつ北海道）は選ばない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: トップの制覇はモードA用とモードD用の2本とし、合算の全体制覇率を出してはならない。
- **FR-002**: トップのA制覇はモードAの正解のみで進めなければならず、B/C/Dの正解で進めてはならない。
- **FR-003**: トップのD制覇はモードDの正解のみで進めなければならず、A/B/Cの正解で進めてはならない。
- **FR-004**: トップにB/Cのクリア数を出してはならない。
- **FR-005**: モード選択ではA/B/C/Dの記号を残し、Aは県当て（地図）、Bは県当て（4択）で練習、Cは市当て（4択）で練習、Dは場所当て（地図）と表示しなければならない。
- **FR-006**: おすすめは、苦戦フォールバック以外ではモードをAまたはDから50%で選ばなければならない。
- **FR-007**: 選んだモードの地方は、そのモードでクイズが成立する対象地方から均等ランダムで選ばなければならない。モードAでは都道府県が1つだけの地方（北海道）を対象から除かなければならない。モードDでは北海道を含めてよい。そのモードで全難易度が制覇90%以上の地方は引き直さなければならない。Aの90%判定と引き直しは、Aの抽選対象から除いた地方を「全市」に含めない。
- **FR-008**: 選んだ地方×モードでは、制覇90%未満のうち最も易しい難易度を選ばなければならない。入門が90%で中級が50%なら中級とする。
- **FR-009**: おすすめの出題は未クリア優先でなければならない。モードDの未クリア判定は市区町村コード単位とし、同一県・同一市名の他コードをクリア済みとみなしてはならない。
- **FR-010**: そのモードについて抽選対象の全市地方が制覇90%以上のときは、地方の引き直しをやめ、AとDの地方×難易度マスのうち開始できるものから制覇率が最小のものを選ばなければならない。同率は均等ランダムとする。開始できないマス（AまたはBかつ北海道）は候補にしてはならない。
- **FR-011**: おすすめがAを選んだときだけ、直近Aセッションの正答率が低ければモードをD50%・B25%・C25%に差し替えなければならない。地方と難易度は差し替え前のA抽選結果を維持しなければならない。差し替え後のBは、A抽選が北海道を含まないため開始不能にならない。直近セッションの切り出しと正答率は、表示1問につき1件に正規化した結果で行い、保存行数で行ってはならない。同じ直近Aセッションに対する差し替えは1回までとし、その後のA抽選は差し替えてはならない。
- **FR-012**: おすすめがDを選んだときは、正答率を理由にモードをB/C/Dへ差し替えてはならない。
- **FR-013**: 直近Aセッションが無いときはFR-011の差し替えをしてはならない。
- **FR-014**: 制覇90%と難易度選択は地方×難易度のマスで見なければならない（全国一枚の難易度ではいけない）。
- **FR-015**: おすすめ決定後にクイズを完了したら、おすすめの表示は古い推薦のまま残ってはならない。
- **FR-016**: 間隔反復の復習はモード別に維持しなければならない。
- **FR-017**: 正答率推移・苦手ランキングなどトップから外す項目は、詳細分析ページへ移す前提としなければならない。詳細分析ページの画面実装はこの仕様の対象外とする。
- **FR-018**: A制覇とD制覇の定義は、トップのバー・おすすめの90%判定・未クリア優先で一致しなければならない。Dは市区町村コード単位で、022の(name, prefecture)集約より本仕様を優先する。
- **FR-019**: モードDの正誤判定と解答フィードバックは出題の市区町村コードと一致しなければならない。同一の保存名を持つ別コード（政令市の他区など）のタップを正解としてはならない。
- **FR-020**: モードDの回答前の出題表示は、学習者が出題コードを他の市区町村コードと区別できなければならない。政令市の区は、市名だけ（例: 札幌市）では足りず、区が分かる表示を出さなければならない。

### Key Entities

- **県当て制覇（A）**: 市区町村名から所属県を地図で答えられたか。トップのAバーとおすすめのAマス。
- **場所当て制覇（D）**: 地図上の位置を当てられたか。トップのDバーとおすすめのDマス。
- **練習（B/C）**: 同じ所属県知識の4択。全国制覇に含めない。
- **地方×難易度マス**: おすすめが90%と次レベルを見る単位。AとDで別。
- **おすすめ**: A/D抽選のあと地方・難易度・必要ならBCD。
- **詳細分析**: 後続仕様。トップから外した履歴・練習数字の置き場。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Aのみで全市区町村を正解した学習者のトップAバーは100%になり、Dバーは0%のままである（D未プレイ時）。
- **SC-002**: B/Cのみ正解してもトップのAバー・Dバーは増えない。
- **SC-003**: トップに合算の全体制覇率もB/Cクリア数も無い。
- **SC-004**: 苦戦しておらず、かつ選んだモードが最小制覇マス規則（FR-010）に入っていないとき、最初のモード抽選は十分な回数でAとDが各々およそ40〜60%に入る。最終的に出すモードはFR-010のあと偏ってよい。
- **SC-005**: ある地方のA入門90%・A中級50%のとき、Aかつその地方が選ばれれば中級が選ばれる。
- **SC-006**: 90%済み地方は、まだ90%未満マスがある地方が残っているあいだおすすめに出ない。
- **SC-007**: A引きかつ直近A正答率が低く、そのセッションでまだ差し替えていないとき、形式はD/B/Cに分かれ、地方・難易度はA抽選のままである。同じセッションで既に1回差し替えたあとのA引きはAのままである。
- **SC-008**: モード選択でBとCが練習、Aが県当て地図、Dが場所当て地図と読める。
- **SC-009**: 政令市のある区だけモードDで正解しても、同市の他区はD未クリアのまま残り、未クリア優先の対象になる。
- **SC-010**: 政令市のある区がDの出題のとき、同市の別区をタップしてもその問いは不正解であり、出題コードはクリアにならない。
- **SC-011**: 政令市の区のD出題は、回答前に区が分かる。

## Assumptions

- 地方の集合は現行のおすすめと同じ（北海道〜九州など既存の地域区分）。県当ておすすめの抽選対象からは北海道を除く。
- 難易度は現行の入門／中級／上級／達人。
- 「正答率が低い」は現行おすすめの直近セッション判定を流用する。
- 未クリア優先の既定ONなど022の出題規則は、選ばれたモード×地方×難易度のプールに対して維持する。ただしモードDの出題単位は022の(name, prefecture)集約ではなく市区町村コードとする。B/Cの集約は022のまま。
- モード選択URLのA/B/C/Dは変えない。
- 023のA→Bクレジットは実装せず、本仕様が正とする。

## Out of Scope

- 詳細分析ページの画面・情報設計（後続仕様）
- B/C/Dの廃止、モード統合
- 復習レコードの統合
- 都道府県クイズ
- 新しい正答率閾値の導入
