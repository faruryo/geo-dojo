# Quickstart & Validation Guide: クイズ解答時のリッチフィードバック演出と補足情報表示

**Feature**: `029-rich-answer-feedback`  
**Date**: 2026-09-20  
**Status**: Complete  

---

## 1. 概要

本ガイドは、`029-rich-answer-feedback`（クイズ解答時のリッチフィードバック演出と補足情報表示）の機能が正しく実装されているかをエンドツーエンドで確認するための検証シナリオと自動テスト手順を定義する。

---

## 2. 前提条件 & セットアップ

```bash
# ローカルDBとNext.js開発サーバーの起動
supabase status || supabase start
pnpm dev
```

ブラウザで `http://127.0.0.1:3000` を開く（モバイル表示モード: 幅 375px に設定）。

---

## 3. 手動検証シナリオ

### シナリオ 1: 補足情報表示（難易度・人口）の検証 (US1)

1. **通常市町村（Mode B または D）**:
   - `http://127.0.0.1:3000/quiz/municipality/D` を開く。
   - 任意の市区町村をタップして正解または不正解にする。
   - **確認**:
     - `TopHud` 直下に不透明カード（`bg-[#111111]`）が現れる。
     - 正否バッジ、自治体名、よみがな、難易度（例: `☆☆ 中級`）、人口（例: `約4.4万人`）が表示される。
     - 下部帯（`BottomHud`）はお題（例: `館山市（千葉県）`）が表示されたまま高さが変わらない（44px固定）。
2. **政令指定都市の合算（Mode B または A）**:
   - 静岡市や大阪市などの政令市が出題された問題に解答する。
   - **確認**: 区単体の人口ではなく、全区合算の市総人口（例: 静岡市「約69.3万人」）が表示される。
3. **同名最多県（Mode A: 池田町・4県）**:
   - Mode A で池田町（北海道、福井県、長野県、岐阜県）を出題・解答する。
   - **確認**:
     - カード内に全4県の内訳（県名・よみがな・人口）がスクロールバーなしで収まり、カード最大高さが 112px を超えない。
     - 地図上の正解県（4県すべて）がハイライトされる。
4. **不正解時の表示**:
   - 誤った選択肢または地点をタップする。
   - **確認**: 「✗ 不正解」とともに正解自治体のよみがな・難易度・人口が表示される（下部帯はお題据え置き）。

---

### シナリオ 2: 進行制御・スキップ・誤タップガードの検証 (US2)

1. **手動スキップ（3つのトリガー）**:
   - 解答フィードバック中に以下をそれぞれ試す:
     - 下部帯（`BottomHud`）の背景をタップ。
     - 上部フローティングカード本体をタップ。
     - キーボードの `Space` または `Enter` キーを押す。
   - **確認**: いずれの操作でも即座に次問へ遷移する。
2. **スキップから除外される操作**:
   - フィードバック中に地図面をドラッグ・ピンチズームしたり、TopHud の離脱ボタンを押す。
   - **確認**: 次問へのスキップは発火せず、地図操作や離脱ダイアログが正しく動作する。
3. **キーリピート抑止**:
   - Mode A 等で Space キーを押しっぱなしにする。
   - **確認**: キーリピートによる連続スキップは発生せず、一度キーを離すまで次問スキップを受け付けない。
4. **誤タップガード (250ms)**:
   - スキップ後、次問へ切り替わった直後（250ms以内）に地図や選択肢を素早く連打する。
   - **確認**: 連打の最初のタップが誤回答として認識されず破棄される。
5. **自動遷移 (2.0秒)**:
   - 何も操作せずに待機する。
   - **確認**: 保存完了後、一律 2.0秒 経過で自然に次問へ遷移する。
6. **スキップ描画遷移時間 (SC-004)**:
   - スキップ操作（帯・カード・Space）を行った際、保存完了から 50ms 以内に次問のレンダリング遷移が開始されることを確認する。

---

### シナリオ 3: 達成感を高める正解演出（和音SE・紙吹雪）の検証 (US3)

1. **連続正解とピッチ上昇**:
   - 1問目から4問目まで連続で正解する。
   - **確認**:
     - 1問目: 基準和音SE、「正解！」
     - 2連続: 全音上の和音SE、「いいね！」、カード内に「2連続」チップ
     - 3連続: 2全音上の和音SE、「お見事！」、カード内に「3連続」チップ
     - 4連続: 3全音上の和音SE、「すごい！」、カード内に「4連続」チップ
2. **5連続達成時の演出（紙吹雪 & ファンファーレ）**:
   - 5問目を正解して 5連続 を達成する。
   - **確認**:
     - オクターブ上のトーンを加えた華やかなファンファーレ和音SE（0.34秒）が鳴る。
     - 「完璧！」ラベルとともに、画面上に軽量なCSS紙吹雪が舞う。
3. **6連続以降の維持と乱発防止**:
   - 6問目を正解する。
   - **確認**:
     - 最高音程の通常和音SEが鳴り、「完璧！」ラベルと「6連続」チップが表示される。
     - **紙吹雪は発火しない**（5連続達成時のみの1回限定）。
4. **リセット確認**:
   - 途中または6問目で不正解（またはMode Dタイムアウト）にする。
   - **確認**: Streak が 0 にリセットされ、次の正解は 1問目（「正解！」、基準和音）から再開される。
5. **アクセシビリティ（Reduced Motion & スクリーンリーダー）**:
   - OS設定で「視覚効果を減らす（Reduce Motion）」を有効にする。
   - **確認**: 紙吹雪・バウンス・パルス演出が無効化され、静的な表示となる。
6. **パフォーマンス・ロングタスク検証 (SC-005)**:
   - Chrome DevTools の Performance パネルで CPU 4x スローダウンを有効化し、375px 実機表示・Google Maps 稼働状態でクイズ（解答〜紙吹雪演出）を実行・記録する。
   - **確認**: 50ms 超のロングタスク（フレーム落ち・赤線）が発生しないこと。
