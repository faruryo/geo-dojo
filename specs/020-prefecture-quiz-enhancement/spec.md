# Feature Specification: 都道府県クイズ強化とタイムアタックモード (B003)

**Feature Branch**: `020-prefecture-quiz-enhancement`  
**Created**: 2026-08-15  
**Status**: Draft  
**Input**: User choice: "設定画面追加（出題数10/20/47問・地方絞り込み・タイムアタックモード）＋クリアタイム計測・結果表示＋苦手優先出題"

---

## 1. 背景と動機 (Background & Motivation)

現在の都道府県クイズ（`/quiz/prefecture`）は、常に全47都道府県からランダムに10問が出題される固定仕様となっており、市区町村クイズのような地方別の絞り込みや出題数の変更、学習効率を高める「苦手優先出題」、解答スピードを競う「タイムアタックモード」が存在しなかった。

本機能により、**出題地域（地方別/全国）・出題数（10/20/全問）・クイズ種別（通常学習 / タイムアタック）** を自由に設定できる設定画面を導入し、クリアタイムの計測・自己ベスト記録・苦手優先出題を提供することで、都道府県学習のやり込み度と利便性を大幅に向上させる。

---

## 2. ユーザーストーリー (User Scenarios & Testing)

### User Story 1 - 都道府県クイズの設定（地域・出題数・苦手優先） (Priority: P1)

ユーザーは都道府県クイズ開始前に、出題地域（全国または指定した地方）、出題数（10問、20問、全問）、苦手優先出題を自由に設定してクイズを開始できる。

**Why this priority**: 学習者の習熟度や目的に合わせた柔軟な学習を可能にするため。

**Independent Test**:
- 地域で「東北」を選択した場合、東北6県のみから出題されることを確認する。
- 出題数で「全問」を選択した場合、対象地域の全件が出題されることを確認する。

**Acceptance Scenarios**:
1. **Given** 設定画面を開いたとき, **When** 出題地域（例: 関東）を選択しスタートする, **Then** 関東地方の都県のみが出題される。
2. **Given** 出題数選択で「全問」を選択したとき, **When** クイズを開始する, **Then** 対象地域の全件が出題数となる。
3. **Given** 苦手優先が有効なとき, **When** クイズを開始する, **Then** 過去の誤答率が高い都道府県が優先的に出題キューの前方に配置される。

---

### User Story 2 - タイムアタックモードとクリアタイム計測 (Priority: P1)

ユーザーは「タイムアタックモード」を選択してクイズに挑戦でき、クリアまでの合計所要時間（分:秒.ミリ秒）が計測され、自己ベストタイムが記録・更新される。

**Why this priority**: 都道府県の即答力を高めるゲーミフィケーション・スピード練習の需要に応えるため。

**Independent Test**:
- タイムアタックモードで開始し、全問回答後にクリアタイムが表示されることを確認する。
- 過去の自己ベストを更新した際、「自己ベスト更新！」バッジが表示されることを確認する。

**Acceptance Scenarios**:
1. **Given** タイムアタックモードでクイズを開始したとき, **When** 回答を進める, **Then** リアルタイムに経過時間タイマーが表示される。
2. **Given** タイムアタック完了時, **When** 結果画面を見る, **Then** 合計クリアタイム（例: `0:24.35`）と自己ベストタイムが表示される。
3. **Given** 新記録を達成したとき, **When** 結果画面を見る, **Then** 自己ベスト更新バッジが表示され、新タイムが保存される。

## 3. 要求事項 (Requirements)

### 機能要件 (Functional Requirements)

- **FR-001**: 都道府県クイズの出題配列を生成する純粋関数 `buildPrefectureQuestions` を `lib/quiz/prefecture-quiz.ts` に提供しなければならない。
- **FR-002**: 都道府県クイズのクリアタイム整形関数 `formatClearTime`（ミリ秒から `M:SS.ms` または `SS.ms` 形式への変換）を提供しなければならない。
- **FR-003**: 設定画面（Setup Phase）を提供し、地域選択（全国/地方別）、出題数（10/20/全問）、モード（通常/タイムアタック）、苦手優先トグルを設定可能にしなければならない。
- **FR-004**: タイムアタックモードにおける自己ベストタイムは localStorage（`geodojo-prefecture-best-time`）に保存・管理されなければならない。
- **FR-005**: 完了画面（Result Phase）において、正答数・正答率・所要時間・苦手な都道府県（読み仮名付き）・自己ベストを表示しなければならない。
- **FR-006**: 375px モバイル画面およびダークモードに最適化された UI でなければならない。

---

## 4. 成功基準 (Success Criteria)

- **SC-001**: ユーザーは任意の地域と問題数を選んで都道府県クイズをプレイできる。
- **SC-002**: タイムアタックモードで全問回答後、正確なクリアタイムと自己ベストが確認できる。
- **SC-003**: 誤答した都道府県が読み仮名付きで一覧表示される。
