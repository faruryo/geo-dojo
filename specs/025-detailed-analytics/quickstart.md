# Quickstart: 詳細分析ページ (025-detailed-analytics)

## 検証シナリオと手順

### 1. ナビゲーションとページ遷移の検証
1. 開発サーバーを起動: `pnpm dev`
2. ブラウザで `http://127.0.0.1:3000` を開く。
3. 下部のボトムナビゲーションに「分析」タブが存在することを確認する。
4. 「分析」タブをタップし、URLが `/analytics` に遷移し、タブがハイライトされることを確認する。
5. 「ホーム」タブをタップし、`/`（ダッシュボード）に戻れることを確認する。

### 2. データ表示の検証（回答履歴ありユーザー）
1. ログイン済みアカウントで `/analytics` を開く。
2. 以下の要素が縦スクロールで正常に描画されることを確認する：
   - 上部: 4枚のサマリーカード（累計出題数、全体正答率、県当て(A)制覇率、場所当て(D)制覇率）
   - フィルターバー: 期間切り替え（7日/30日/全期間）、地方セレクト、モードセレクト（全て/県当て(A)/県当て練習(B)/市当て練習(C)/場所当て(D)）
   - 正答率推移グラフ（折れ線・バーチャート）
   - 難易度別クリア進捗（入門〜達人）
   - 苦手市区町村ランキング
3. フィルターバーで「直近30日」や特定の「地方（例: 東北）」「モード（例: 場所当て(D)）」に切り替えた際、推移グラフと苦手ランキングが即座に連動更新されることを確認する。

### 3. 初期状態の検証（回答履歴0件ユーザー）
1. 新規アカウント（または回答履歴のないテストアカウント）でログインし `/analytics` を開く。
2. エラーにならず、EmptyState（「まだ回答データがありません」等のメッセージとクイズ開始ボタン）が表示されることを確認する。

### 4. モバイル表示の検証
1. ブラウザの開発者ツールで表示幅を `375px`（iPhone SE等）に設定する。
2. 水平スクロールが発生せず、全コンポーネントが適切なマージン・パディングで縦に綺麗に並ぶことを確認する。
3. ダークモード背景（`#111111`）で文字やグラフのコントラストが担保されていることを確認する。

### 5. Automated Tests
```bash
pnpm type-check
pnpm lint
pnpm test
```
