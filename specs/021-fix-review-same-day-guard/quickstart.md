# Quickstart: 021-fix-review-same-day-guard

## 手動検証手順

### 1. 復習クイズ完了後の件数減算と無限ループ解消の確認

1. 期日超過の復習アイテムを持つユーザーでログイン。
2. `/quiz/review` を開き、復習クイズ（例えば20問）をプレイして全問正解でクリア。
3. 結果画面を確認:
   - 残り件数が正解数分減少していること。
   - すべて消化した場合は「今日の復習はありません」または完了画面になること。
   - まだ残りがある場合は、「続けて復習する（残り N 件）」の件数が正しく減算されていること。
4. 「続けて復習する」を押下:
   - 直前で正解した問題が再出題されず、残りの問題が出題されること。

### 2. 単体テストと型チェック・Lint の実行

```bash
pnpm test
pnpm type-check
pnpm lint:ratchet
```
