# Data Model: 詳細分析の期間初期値と長期の正答率推移

スキーマ変更なし。新しい永続テーブルはない。

## 期間選択

| フィールド | 値 |
|---|---|
| 学習者 | 認証ユーザー ID |
| 期間 | `7d`（7日） / `30d`（30日） / `all`（全期間） |
| 置き場所 | この端末のみ。キーは学習者ごとに分ける |
| 初期値 | 保存が無い、読めない、上記 3 値以外なら `all` |
| 覚えないもの | 地方（初期値 `全国`）、モード（初期値 `all`） |

## 正答率の点

既存の推移 1 点（日付キー、難易度別正答率、全体正答率、正解数、回答数）を維持する。変わるのは日付キーの粒度だけ。

| 期間 | キー | 条件 |
|---|---|---|
| `7d` / `30d` | `YYYY-MM-DD`（JST の日） | 常に日 |
| `all` | `YYYY-MM-DD`（その週の月曜、JST） | 最初の回答日と最後の回答日の JST 暦日差が 364 以下 |
| `all` | `YYYY-MM`（JST の暦月） | 暦日差が 365 以上 |

- 回答が無い週・月の点は作らない。
- 暦日差 0（同日だけ、1 件だけ）は週キーで 1 点。
- 境界: 差が 364 なら週、365 なら月。
- 1 点への足し上げ（Mode A は同名を 1 問、難易度は代表値）は今と同じ。

## 表示用ラベル（保存しない）

| キー | 軸（全期間のみ） | 点を押した説明 |
|---|---|---|
| 週 `YYYY-MM-DD` | `M/D`（例: `10/6`） | `YYYY/M/Dの週` |
| 月 `YYYY-MM`、すべて同じ年 | `M月`（例: `10月`） | `YYYY年M月` |
| 月 `YYYY-MM`、年が複数 | `YY/M`（例: `26/10`） | `YYYY年M月` |

7日・30日の軸はキー文字列のまま。全国制覇推移の点は日次のまま。
