# 制覇はAとDを別ゲージ、おすすめはA/D抽選

日付: 2026-08-30

## 役割

| 記号 | 表示 | 全国制覇（トップ） |
|---|---|---|
| A | 県当て（地図） | Aバー |
| B | 県当て（4択）練習 | 含めない |
| C | 市当て（4択）練習 | 含めない |
| D | 場所当て（地図） | Dバー |

合算の全体%は出さない。B/C練習クリアはトップに出さない。詳細分析は後続仕様。

## おすすめ

1. AまたはDを50%。
2. そのモードの地方を均等ランダム。全難易度90%以上の地方は引き直し。
3. その地方×モードで、90%未満のうち一番易しい難易度。未クリア優先。
4. そのモードの全市が90%以上 → AとDのマスから制覇最小。同率は均等ランダム。
5. Aを引いたときだけ、直近Aセッション正答率が低ければ D50% B25% C25%。地方・難易度は維持。
6. D引きでは正答率フォールバックなし。コールドスタート（Aセッション無し）もフォールバックなし。
7. クイズ完了後はおすすめキャッシュを捨てる。

## トップ

おすすめ、A制覇、D制覇。推移・苦手・B/Cは詳細分析へ移す前提。
