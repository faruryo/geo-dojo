# DBスキーマ変更時のドキュメント更新ルール

## 概要
`lib/db/schema.ts` に変更（テーブルの追加・変更・削除、カラムの追加・変更、型の変更）を加えた場合、**必ず同時に `docs/db-schema.md` を更新**してください。

## 必須更新手順
1. **`docs/db-schema.md` の Mermaid ER図の更新**:
   - テーブル間リレーションシップ（1対多など）や、変更されたテーブル・カラムを更新する。
2. **テーブル＆カラム仕様一覧の更新**:
   - 新規テーブル追加時: 役割（💡1行サマリ）と詳細カラム表を新規追記。
   - 新規・変更カラム時: 物理名、型、制約、日本語名、および**実際の取れる値・具体例**を記載。
